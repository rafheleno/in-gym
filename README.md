# flutter_application_3

    # Estatistica para mega sena 
        
        Este projeto tem como core principal um apicativo voltado a academias em varias modalidades, musculação, natação, balé e outros, o propósito é criar uma plataforma pessoal para o ususario obter informações no formato feeds, pois proporciona noticias geradas pelo estabelecimento ou blocos de informação pessoal, como uma agenda onde estarão marcados os dias de treino por exemplo, tambem serve como uma ponte entre o treinador e o usuario. Conforme se gera informação do usuario pelo treinador o mesmo pode enviar mensagens, tais como recomendações.
        O aplicativo ira manter uma listView de pequenos blocos que irão conter mensagens e imagens advindas de uma API-REST do proprio estabelecimento.

        API-REST.

        A ideia de se criar um APP é simplemente, trazer conforto ao usuario, informação mediante aos pilares da boas praticas e segurança, Confidencialidade, Disponibilidade e Integridade, conecta-lo a uma Api ira promover potencial satisfação por ambos os lados, o estabelecimento que ira manter um vinculo de fidelização e um canal ecommerce vasto a se explorar, e do outro lado, o cliente que tem um canal aberto direto com o profissional, levando tambem em consideração outros recursos que o APP ira disponibilizar.
